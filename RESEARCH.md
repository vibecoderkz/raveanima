# Anima research log

## 2026-10-18 — Recon agent on a closed competitor
- A background agent mapped Rive from public pages only in ~7 min / 37 tool calls: 24 screens, 130 feature rows with source URLs.
- It found a fact a human would likely miss: Rive deleted the readable `.riv` definitions (`dev/defs`) from the public runtime repo on 2026-08-25; last copy at commit `845a82a9`.
- Pricing pages contradicted the docs (video export, AI agent on Free); the agent flagged both as uncertain instead of picking one. Good default.
- Gap it surfaced shaped the product: no Lottie export, no Linux, MCP only with the app window open. Anima targets exactly those.

## 2026-10-18 — Designing a tool for agents first
- One command registry for UI, CLI, MCP and the live bridge removed a whole class of "the agent can't do what the button does" bugs.
- Strict zod schemas (`strictObject`) turn agent typos into precise errors (`props: Unrecognized key: "widht"`), which an LLM fixes in one retry. Loose schemas silently ignore them.
- A contact sheet (N frames in one PNG with timestamps) lets a model judge motion in one look; single-frame previews hide easing problems such as backOut overshoot.
- `command_batch` (atomic, one undo step) let a whole 17-step scene with 4 shapes and 6 animated tracks go in one call.
- Agent-built icon: the app icon was drawn by Anima's own CLI from a 3-command batch, rendered with Skia.

## 2026-10-18 — Claude Code building it
- Core (model, commands, easing, Lottie) written in one pass; 15/15 tests passed on first run after fixing one wrong expectation in the test itself.
- Workspace pitfall: vitest 5 pulled Vite 8 into the root while the app pinned Vite 7; the React plugin then failed with `Missing field moduleType`. Fix: align on one Vite major.
- Built-in browser testing caught UI bugs that typecheck could not: unfilled SVG diamonds (rendered black), a popover positioned against the viewport, selection boxes inflated by bezier handles.

## 2026-10-18 — Agent draws a "realistic" owl through commands only
- 442 nodes and 32 animated tracks, generated by one script that only calls `node.add` / `keyframe.set` (`examples/owl.ts`). No hand-drawn assets.
- Three iterations judged by rendered frames: v1 read as cartoon (cat-like ear tufts, detached wing flaps, breast "streaks" that looked like bird icons). Looking at the render, not the code, is what caught these.
- A contact sheet hid the blinks (0.25 s) between its 12 frames; a single frame pulled from the MP4 at 1.32 s confirmed them. Contact sheets need a "events" mode that samples around keyframes.
- Pure vector primitives limit realism: no blur, masks or texture, so depth comes from layered gradients and hundreds of small strokes. Masks, blur and image fills are the next engine features that matter for realism.
- Lottie export of the 442-node scene (303 KB) rendered the same frame in lottie-web 5.12 as Anima's own renderer: one engine, two players, same pixels.
- Live bridge: `anima mcp --live` loaded the file into the open Tauri window; requests without the token or with a browser Origin get 401.

## 2026-10-18 — v0.2: state machines, editor parity, agent-driven testing
- `sm.simulate` (scripted wait/set/fire/pointer steps returning the state history) lets an agent verify interactivity without a browser; the owl's Idle→Alert→Hoot→Alert→Idle loop was proven headless before any UI existed.
- The atomic `batch` caught my own id mistakes (preset "draw" on an image): the whole batch rolled back with a readable error instead of leaving a half-built scene. Agents benefit from all-or-nothing writes.
- Two silent failure modes found only by looking at renders: Skia's font loader is not recursive and skips symlinked dirs (text fell back to monospace), and `t % duration` float drift left trim at 1e-31 instead of 0. Contact sheets catch what tests don't.
- A parallel sub-agent wrote the SVG importer against a fixed interface while I built the renderer; it worked first try because the contract (`parseSvg → nodes`) was set up front.
- Crossfading between states needs both poses computed from the rest pose; blending from the "current" document left properties stuck when the target state had no animation.
- The editor preview reuses the same `StateMachineRuntime` as the web player and `sm.simulate`, so one code path is tested three ways (agent, editor, browser).

## 2026-10-19 — логотип DZ как первый реальный проект
- Знак DZ (3 контура, анимация сборки, цикл загрузки, state machine intro/hover) собран одним скриптом только из команд (`design/dias-now-logo/out/motion/build-motion.mts`), полная пересборка со всеми экспортами около 50 с. Геометрия с дугами сошлась с эталонным SVG до уровня антиалиасинга; `import.svg` дал те же bounds, что и свой конвертер дуг.
- Брендовые цвета вскрыли то, чего не видно на тестовых сценах: mp4/mov кодируются матрицей BT.601 без тегов (#3A2CFF в плеере выходит как #3738FF); GIF получает задержки 10/20 мс при fps 60 (браузеры растягивают 1 cs до 100 мс); Lottie из прозрачного холста содержит непрозрачный слой Background (lottie-web рисует чёрный). Обход: кадры через `export .png --time`, свой ffmpeg с BT.709, вычистка слоя из JSON.
- `sheet --keys` берёт только времена ключей и их середины, поэтому быстрый перелёт (cubic-bezier 0.16,1,0.3,1: 95% хода за 100 мс) в него не попал; пришлось делать вариант документа с короткой шкалой. Нужны `--from/--to` или список времён.
- Слушатели state machine на группе дают leave+enter при переходе курсора между детьми (Hover, Idle, Hover, анимация стартует заново); лечится одним прозрачным rect поверх всего знака (hit-test берёт верхний узел, opacity 0 не ловится, а fill с нулевой альфой ловится).
- Проверка глазами по плотному листу и пиксельное сравнение с эталонным SVG заняли меньше времени, чем поиск причин в коде: именно рендер показал, что у overshoot из ТЗ эффект "зажатого" шва держится около 280 мс (ease почти мгновенный, 6 ед. хода сидят до 360 мс).
